# Examples

## Text Brief

```bash
node bin/video-prep-skill.js fixtures/sample-repo --format text
```

Use the text brief when an agent is preparing a recording plan or handoff.

## JSON Brief

```bash
node bin/video-prep-skill.js fixtures/sample-repo --format json
```

Use JSON output when another tool will transform scenes into cards, subtitles, or an editing checklist.
